# com.rickit.autoui

Unity package source: [Assets/RicKit/AutoUI](Assets/RicKit/AutoUI). See its [README](Assets/RicKit/AutoUI/README.md) and [CHANGELOG](Assets/RicKit/AutoUI/CHANGELOG.md).

Releases: OpenUPM publishes each semver tag (`0.6.0` or `v0.6.0`) and finds the package in `Assets/RicKit/AutoUI` by itself. To release, update `package.json` and the CHANGELOG on `main`, then push a tag equal to the version. The `Check release tag` workflow fails if the tag and `package.json` disagree.

The package is maintained in the Auto UI tool repository and synced here with `tools/sync_unity_package.ps1`.

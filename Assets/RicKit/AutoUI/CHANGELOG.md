# Changelog
## [0.6.0] - 2026-10-28
First release on OpenUPM (previously embedded as `com.autoui.pipeline`).
### Removed
- Runtime assembly and the `AutoUiView` component. Generated prefabs carry only uGUI components; node IDs are mapped to prefab objects in the page manifest (`nodes`) instead.
- Direct import into `SharedSprites` and the `Tools → Auto UI` window; import plans replace them.
### Changed
- Re-import finds existing prefab objects through the manifest's node paths, keeping file IDs and renaming objects in place.
### Kept
- `AutoUiPlanImporter` (command line and menu), `AutoUiPrefabDump`, `AutoUiPreview`.
### Migration from the embedded `com.autoui.pipeline`
- Delete `Packages/com.autoui.pipeline` and add `com.rickit.autoui` from OpenUPM.
- Remove the `AutoUiView` component from prefabs generated by earlier versions (it would become a missing script), then re-import the page once so the manifest gets node paths.
